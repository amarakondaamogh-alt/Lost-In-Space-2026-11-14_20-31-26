# Lost In Space

A 10-level 2D platformer made in Unity. You're an astronaut lost in space: collect the energy crystals, step on the switch to unlock the door, and get back to your spaceship. Use bounce pads to reach high platforms and avoid the hazards.

## Controls

| Action | Keys |
| --- | --- |
| Move | A / D or Left / Right arrows |
| Jump | Space (or W / Up arrow) |
| Pause | Esc |

Gamepads work too (left stick, A / bottom button, Start).

## Goal (every level)

1. Collect all the energy crystals.
2. Step on the switch to unlock the door.
3. Go through the door and reach the spaceship.

Beat Level 10 to finish the game.

## Opening the project

- Unity version: **6000.6.7f1** (Unity 6)
- Open the `Lost In Space` folder from Unity Hub.
- After pulling, run **Lost in Space > Set Up Everything** once if any level looks unwired.
- Start from the `MainMenu` scene to play the full game.
